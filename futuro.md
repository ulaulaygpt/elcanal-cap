# FUTURO DEL CAP
## Plantilla pública · hipótesis y desarrollos no activos

Este archivo no es un plan ni una lista de tareas. Sirve para que una idea interesante no invada el sistema activo antes de demostrar que resuelve una deriva real.

## Reglas

- Nada aquí se activa automáticamente.
- Una idea no gana prioridad por parecer elegante o novedosa.
- Para pasar al núcleo debe existir una necesidad observada, evidencia suficiente y decisión humana.
- Si una idea puede esperar, debe esperar.
