# CAP v0.3 — EDICIÓN PÚBLICA

Fecha: 2026-10-04

Este paquete es la **distribución pública y portable** del Canal Activation Protocol (CAP).

No es una copia de una instancia personal. No contiene memoria privada, datos de operador, infraestructura, expedientes ni contexto longitudinal de ninguna persona concreta.

La instancia privada CAP 2.1 utilizada durante el desarrollo permanece separada y no forma parte de esta publicación.

Regla de separación:

> Se publica la arquitectura y el método. No se publica la memoria del operador.

- CAP v0.2 — 2026-04-12 — DOI 10.5281/zenodo.19545927
- CAP v0.3 — 2026-10-04 — edición pública actual

La publicación canónica y el DOI de esta versión se gestionan en Zenodo. El paquete permanece idéntico entre repositorios para permitir verificación por hash.
